Configuração copiável

Configure o serviço uma vez, com calma.

Execute comandos na raiz do clone do repositório. Substitua nomes apenas se tiver escolhido outro nome para o banco. O painel pode mudar de rótulo; os conceitos obrigatórios são Pages, saída dist e binding D1 chamado DB.

1. Verificação local

Instale Node.js 20 ou superior. Abra PowerShell na raiz do clone e confirme que os testes e o build passam.

npm ci
npm test
npm run build

Confirme que dist/ contém index.html, css/, js/, assets/, _headers e _routes.json, sem guias-cloudflare/, SQL, testes ou segredos.

2. Banco D1

  1. Crie o banco

    No painel: Workers & Pages ou Storage & databases → D1 → Create database. Nome sugerido: linux-flow. Não há dados reais no Aiven para importar.

  2. Aplique o esquema

    Com Wrangler autenticado, rode o comando abaixo; ou cole o conteúdo de sql/d1-schema.sql no Console D1. Não cole a documentação inteira.

    npx wrangler d1 execute linux-flow --remote --file=sql/d1-schema.sql

    Confira as tabelas synced_profiles, ranking_attempts, feedback_comments, pro_requests, game_rooms e study_groups.

As rotas em functions/api/ são detectadas pela Pages. Se o painel solicitar Deploy command, não use npx wrangler deploy; confirme que você criou um projeto Pages, não Worker. Em Settings → Functions, use data de compatibilidade pelo menos 2026-08-04 e nodejs_compat se a plataforma solicitar. A publicação inicial pode ocorrer antes do binding; nesse período, APIs retornam erro até o banco ser conectado.

4. Binding e ambientes

Em Settings → Bindings → Add → D1 database, escolha o banco e use exatamente DB como nome da variável. Configure Production e faça redeploy. Para Preview, crie outro D1 com o mesmo esquema e vincule-o como DB naquele ambiente: testes de branch não devem escrever em produção.

5. Pix, apenas quando houver operação definida

Em Settings → Variables and Secrets, cadastre PIX_KEY, PIX_RECEIVER_NAME e PIX_RECEIVER_CITY. A chave deve ser secret. O pedido Premium permanece indisponível até as três estarem corretas. Faça redeploy e teste o recebedor no aplicativo bancário antes de aceitar contribuições.

Nunca copie valores reais de Pix, token Cloudflare, chave de acesso de aluno ou exportação D1 para HTML, GitHub, issue ou chat público.

Se aparecer Asset too large, Dynamic require of node:crypto ou Cannot find cwd, abra o diagnóstico dos logs antes de alterar pastas.
