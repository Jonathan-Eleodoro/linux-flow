Comece aqui

Do repositório ao site publicado.

Este conjunto de páginas organiza a revisão do projeto e as ações necessárias para criar a conta, conectar o GitHub, configurar o D1 e manter a aplicação. Abra os arquivos no navegador; os botões “Copiar” ajudam nos comandos.

Estado atual

O código está no GitHub pessoal, mas a Cloudflare ainda não foi configurada. Não há dados reais no Aiven para migrar. Os guias entram no repositório, porém o build por lista de permissão não os copia para dist/; portanto, não aparecem no site Pages.

Sequência recomendada

01 · Antes da conta

Revisão técnica

Veja o que já está protegido e as pendências de segurança, manutenção e experiência de uso.

02 · Identidade

Conta e acesso

Crie a conta com controle institucional, 2FA e permissões individuais.

03 · Infraestrutura

Publicação

Conecte o repositório, crie o D1, aplique o esquema e configure o binding.

04 · Aceite

Validação

Teste site, API, privacidade, comunidade e custo antes de convidar usuários.

05 · Rotina

Manutenção

Tenha comandos de backup, diagnóstico, atualização e Premium manual à mão.

O que este guia não substitui

Ele não concede identidade docente, conformidade jurídica ou avaliação oficial. Para uma turma com menores, alinhe acesso, retenção e responsabilidades com o colégio antes de usar contas reais. As telas do painel Cloudflare podem mudar; confira os links oficiais em cada etapa.
