O que melhorar antes de abrir ao público.

Revisão estática do repositório. “Pendente” indica trabalho real no produto; não é uma falha já explorada. Priorize conforme o tipo de uso.

Achados por prioridade

PrioridadeConstataçãoAção recomendada
Antes de turmasQualquer perfil sincronizado pode criar sala ou grupo e tornar-se “mestre”; functions/api/community.js não valida vínculo docente.Definir aprovação e revogação institucional de professores antes de usar relatórios nominativos com alunos.
Antes de turmasFaixa etária é autodeclarada; a política de retenção de salas, logs, sugestões e e-mails ainda não é automatizada.Definir controlador, finalidade, prazos, acesso e descarte com a escola. Testar pedidos de acesso e exclusão.

Antes de cobrarA liberação Premium usa duas instruções SQL manuais. Uma falha entre elas pode deixar pedido aprovado sem acesso.Conferir pagamento no extrato, executar e verificar cada operação; depois criar ferramenta administrativa transacional com auditoria.

ExperiênciaSalas consultam a API a cada 3 segundos; mobile, foco do guia e espanhol precisam teste manual real.Validar em 320–390 px, teclado, leitor de tela e conexão lenta; medir uso do D1 durante uma turma piloto.

Controles já presentes

Dados e SQL

Queries parametrizadas, binding D1 apenas no servidor, chave de acesso armazenada como hash, autenticação por código e respostas da API com no-store.

Frontend

CSP sem script inline, escape de conteúdo dinâmico, terminal apenas simulado, foco visível, link para pular conteúdo e opção de movimento reduzido.

Publicação

O build seleciona explicitamente os arquivos de dist/. Testes e documentos internos não viram ativos do site. A CSP agora também consta em _headers, inclusive frame-ancestors.

Limites comunicados

O README e a tela de privacidade distinguem perfil local, sincronizado e Premium, além de reconhecer que a identidade e o certificado não são oficiais.

Não publicar capturas de tela com código de acesso, respostas de alunos, comprovantes ou e-mails. O repositório e esta pasta são públicos no GitHub, embora fiquem fora do site Pages.
