Identidade e controle

Mantenha a conta com uma posse clara.

Segundo a conversa salva, a conta já foi criada, o 2FA ativado e o GitHub conectado. Confira os códigos de recuperação em local privado e avance para a configuração Pages.

O código pode continuar no GitHub pessoal Jonathan-Eleodoro/linux-flow. Para a infraestrutura, use o e-mail do projeto linuxflow2026@gmail.com se ele for uma caixa institucional mantida por vocês; documente quem é responsável por sua recuperação.

  1. Confirme a posse da conta Cloudflare

    Se ainda precisar rever o cadastro, abra o cadastro oficial e use um endereço que continuará acessível se uma pessoa sair do projeto. Evite conta compartilhada no uso diário.

  2. Ative autenticação em duas etapas

    Use aplicativo autenticador ou chave de segurança, guarde códigos de recuperação fora do GitHub e confira o e-mail de recuperação. Nunca envie senha, 2FA, token ou código de perfil para este guia.

  3. Conecte só o repositório necessário

    Ao autorizar o aplicativo GitHub da Cloudflare, selecione apenas Jonathan-Eleodoro/linux-flow se o fluxo permitir. Revise as permissões concedidas no GitHub.

  4. Convide pessoas individualmente

    Se o professor precisar administrar a infraestrutura, convide sua conta própria com o papel mínimo necessário. Decida quem pode publicar, editar D1 e configurar Pix. Registre o responsável pelo banco e o suplente.

Decisão prática

O e-mail do projeto é adequado para a propriedade de longo prazo, desde que exista gestão de recuperação e 2FA. O GitHub pessoal pode continuar conectado. Futuramente, se o colégio assumir o produto, avaliem transferir repositório e conta de faturamento com planejamento de acesso e domínio.

Registro para preencher fora do GitHub

  • Responsável pela conta Cloudflare e suplente.
  • Local seguro dos códigos de recuperação.
  • Quem administra GitHub, D1, deploy e Pix.
  • Canal de contato para pedidos de dados e incidentes.
  • Data da próxima revisão de permissões.

Esses dados não devem ser preenchidos neste HTML versionado. Guarde-os em um cofre de senhas ou documento privado com acesso controlado.
